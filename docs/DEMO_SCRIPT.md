# Rehearsal: a three-minute demo

Before presenting, populate `.env.local`, push the schema, run `npm run seed`, and start `npm run dev`. Confirm a seeded agent says “Live voice ready”. Use headphones and allow microphone access. Keep the seeded patient session open as a labeled fallback. Never claim the fixture is a live result.

**0:00–0:30 · An idea becomes a character.** Open `/new`. “Most voice builders make helpful assistants. Rehearsal also makes characters whose job is to resist.” Click Role-play Trainer and create a reluctant patient. Show the generated persona and private rubric in Refine.

**0:30–1:05 · Give it a voice.** Rehearse → Start conversation. “I understand this is uncomfortable. When did the tiredness begin?” Interrupt naturally. Ask whether medication changed. Point out live transcript, speaking state, AI disclosure and observed latency. End and save. If provider processing is not finished, retry after a few seconds.

**1:05–1:35 · Direct a new take.** Refine: “Make the welcome shorter and warmer, and add Hindi.” Preview the before/after diff, apply it, show the new version. Preview an ElevenLabs voice before selecting it, then save.

**1:35–2:00 · Take the stage.** Publish a student practice link and open it. “Students get the brief and a voice character; they don’t get hidden goals or the rubric.” Copy the iframe.

**2:00–2:45 · Find the turning points.** Open Overview and review the session. Show exact quoted evidence, per-item scores, secrets uncovered, and three improvements. Explain that missing or invented evidence cannot earn points. If showing the seeded example, identify it as an illustrative fixture.

**2:45–3:00 · Close.** “A place to practice the conversations you can’t afford to get wrong.” Show receptionist, landlord and viva examiner. End with a student practice link.


## No-key demo

State “offline demo” at the start. Create from a starter, use the labeled scripted text console, edit the form, restore a version, publish the offline practice page, and review the labeled seeded transcript. Voice, AI chat refinement and real grading require credentials. A public offline link cannot talk until the teacher adds ElevenLabs and saves the agent.
